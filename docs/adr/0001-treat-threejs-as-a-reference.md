# Treat Three.js as a reference, not a compatibility target

Three.js supplies the library's recognizable concepts, names, defaults, behavior, and example-driven development model where they translate cleanly. The public API may deliberately diverge to provide Java type safety and deterministic lifecycle management, and the project does not promise source compatibility, complete feature parity, line-for-line example translation, or synchronized releases; this preserves familiarity without importing JavaScript-specific constraints into a long-lived Java API.
