# License JScene3D under Apache 2.0

Status: accepted; release-verification implementation pending as of
2026-09-29.

The licensing decision remains current: the repository contains `LICENSE`, the
root POM declares Apache 2.0, and original source files carry the SPDX header.
The statement below that release verification checks the license recorded the
intended release gate, not tooling that is currently bound to Maven. The root
build has no release profile, and the repository currently configures no Revapi
baseline comparison,
CycloneDX or other SBOM generation, vulnerability or license scanner, GPG
signing, Maven Central deployment, or release-tag automation. That implementation
gap does not supersede the Apache 2.0 decision. The original decision text is
retained below.

JScene3D source and published artifacts use the Apache License, Version 2.0,
identified by SPDX as `Apache-2.0`. The repository contains the official license
text, published POMs declare it, original source files use a concise copyright
and SPDX header, and release verification checks the project license.

Apache 2.0 is permissive and provides an explicit patent grant suitable for a
public reusable library.
Its explicit contribution and patent terms are more detailed than shorter
permissive alternatives, at the cost of a longer license and redistribution
conditions that downstream distributors must retain.
