# Version 0.1 implementation plan

Implementation proceeds as independently verifiable vertical slices. Each
public feature includes its contract tests, Javadoc, and focused example in the
same coherent change.

1. Establish the Java 21 Maven reactor, wrapper, JPMS descriptors, native
   dependency selection, headless tests, formatting, and static analysis.
2. Create and close a GLFW window with an OpenGL 3.3 Core context; visibly clear
   and resize it on macOS ARM64.
3. Implement the headless scene hierarchy and automatic local/world transforms.
4. Add validated perspective and orthographic cameras.
5. Implement owned buffer-geometry storage, validation, mutation versions, box,
   plane and sphere generation, `BasicMaterial`, and `Mesh`.
6. Render the first indexed and non-indexed geometry with deterministic shader
   diagnostics and cleanup.
7. Add `ShaderMaterial`, render ordering, and expanded renderer statistics.
8. Load and render PNG/JPEG textures with linear-sRGB handling and generated
   mipmaps.
9. Complete the focused examples and interactive Solar System Viewer, then
   cross the Public Preview Gate.
10. Qualify provisional platforms, exercise classpath and module-path consumer
    fixtures, and harden Maven Central release metadata for `0.1.0`.

Steps 3 through 5 are complete. `Object3D` provides cycle-safe ordered hierarchies,
controlled position, normalized quaternion orientation, scale, lazy local
matrix composition, and iterative world-matrix maintenance. `Group` adds
semantic grouping, while `Scene` owns an optional immutable linear-sRGB
background `Color`. `PerspectiveCamera` and `OrthographicCamera` provide
validated atomic projection mutation, lazy projection and view matrices, and
world-space camera `lookAt`. `BufferGeometry`, `BufferAttribute`, and
`IndexBuffer` provide owned, validated, versioned CPU-side triangle data with
controlled mutation, draw ranges, bounds, and terminal closure. Plane, box, and
UV-sphere factories produce ordinary buffer-geometry values. `BasicMaterial`
describes an unlit surface, while `Mesh` binds shared geometry and material
descriptions into the scene graph. The headless `HierarchyExample`,
`TransformsExample`, `CamerasExample`, and `BufferGeometryExample` exercise
these features through the public interface. Rendering indexed and non-indexed
geometry is the next slice. Post-0.1 asset loading features remain outside this
plan.
