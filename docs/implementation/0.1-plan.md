# Version 0.1 implementation plan

Implementation proceeds as independently verifiable vertical slices. Each
public feature includes its contract tests, Javadoc, and focused example in the
same coherent change.

1. Establish the Java 21 Maven reactor, wrapper, JPMS descriptors, native
   dependency selection, headless tests, formatting, and static analysis.
2. Create and close a GLFW window with an OpenGL 3.3 Core context; visibly clear
   and resize it on macOS ARM64.
3. Implement the headless scene hierarchy and automatic local/world transforms.
4. Add validated perspective and orthographic cameras.
5. Implement owned geometry storage, validation, mutation versions, and box,
   plane, and sphere generation.
6. Render the first indexed and non-indexed geometry with deterministic shader
   diagnostics and cleanup.
7. Add `BasicMaterial`, `ShaderMaterial`, render ordering, and renderer
   statistics.
8. Load and render PNG/JPEG textures with linear-sRGB handling and generated
   mipmaps.
9. Complete the focused examples and interactive Solar System Viewer, then
   cross the Public Preview Gate.
10. Qualify provisional platforms, exercise classpath and module-path consumer
    fixtures, and harden Maven Central release metadata for `0.1.0`.

The current slice is step 2. The immutable public window-creation options and
vertical-synchronization vocabulary are complete; native GLFW lifecycle and
the remaining Window contract follow next. Post-0.1 asset loading and rendering
features remain outside this plan.
