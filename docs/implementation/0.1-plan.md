# Version 0.1 implementation plan

Implementation proceeds as independently verifiable vertical slices. Each
public feature includes its contract tests, Javadoc, and focused example in the
same coherent change.

1. Establish the Java 21 Maven reactor, wrapper, JPMS descriptors, native
   dependency selection, headless tests, formatting, and static analysis.
2. Create and close a GLFW window with an OpenGL 3.3 Core context; visibly clear
   and resize it on macOS ARM64.
3. Implement the headless scene hierarchy and automatic local/world transforms.
4. Add validated perspective and orthographic cameras.
5. Implement owned buffer-geometry storage, validation, mutation versions, box,
   plane and sphere generation, `BasicMaterial`, and `Mesh`.
6. Render the first indexed and non-indexed geometry with deterministic shader
   diagnostics and cleanup.
7. Add render ordering, expanded renderer statistics, PNG/JPEG textures with
   linear-sRGB handling, generated mipmaps, and transparent rendering.
8. Add constrained custom GLSL through `ShaderMaterial`.
9. Add narrow Lambert lighting with ambient and point lights, complete the
   focused examples and interactive Solar System Viewer, then cross the Public
   Preview Gate.
10. Qualify provisional platforms, exercise classpath and module-path consumer
    fixtures, and harden Maven Central release metadata for `0.1.0`.

Steps 1 through 8 and the implementation portion of step 9 are complete. The
renderer supports indexed and non-indexed geometry, visibility, frustum culling,
reusable opaque and transparent render lists, explicit blend and depth state,
renderer statistics, lazy versioned GPU resources, and renderer-owned overlays.
PNG and JPEG images load into renderer-independent RGBA8 textures; base-color
textures use sRGB decoding and support explicit filtering, wrapping, and
generated mipmaps. Focused examples cover transforms, hierarchies, cameras,
geometry, rendering, controls, textures, transparency, and custom shaders.
`ShaderMaterial` provides immutable GLSL, preprocessor definitions and attribute
requirements, typed mutable uniforms, automatic transform matrices, lazy
compilation, and cached programs. Diffuse `LambertMaterial` rendering supports
ambient light and up to eight point lights.
The interactive Solar System Viewer composes all eight planets, Earth's Moon,
Saturn's transparent rings, a textured star field, scene hierarchy, animation,
lighting, orbit controls, a control panel, and an FPS monitor through public
interfaces. It has passed a native launch smoke test on macOS ARM64. Final visual
acceptance, public API hardening, consumer fixtures, and platform qualification
remain before version 0.1 is complete.
