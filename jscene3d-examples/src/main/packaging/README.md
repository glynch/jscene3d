# JScene3D Examples packaging artwork

`jscene3d-examples-icon.png` is the 1024-pixel application-icon master.
`jscene3d-examples.icns` contains the standard macOS icon representations
generated from that master.

The icon was generated with the built-in OpenAI image-generation tool on
2026-09-12 using these bundled example thumbnails as compositing references:

- `soldier-animation-blending.png`
- `littlest-tokyo.png`
- `water-bottle-model.png`

The final prompt was:

> Create a cohesive, polished macOS application-icon collage from the three
> supplied JScene3D example renders. Preserve the rendered appearance and keep
> each subject recognisable. Use Littlest Tokyo across the upper/background
> scene, the armoured Soldier/Vanguard character as a large lower-left subject,
> and the metallic water bottle as a large lower-right subject. Use a dark navy
> rounded-square composition with restrained violet-blue accents, generous safe
> margins, strong silhouettes, and no text, logos, extra subjects, UI, badges,
> borders, or watermarks.

The corresponding asset notices are maintained in the repository root
`THIRD_PARTY_NOTICES.md` and beside each bundled model.
