# Solar System Viewer texture attribution

The image files in this directory are the 2K Solar System Scope texture pack,
created by Solar System Scope / INOVE. They were downloaded from the
[Solar System Scope texture library](https://edu.solarsystemscope.com/textures/)
on 2026-08-31.

The textures are licensed under the
[Creative Commons Attribution 4.0 International License](https://creativecommons.org/licenses/by/4.0/).
The complete license text is included in `LICENSE-CC-BY-4.0.txt`. These assets
are not covered by JScene3D's Apache License 2.0.

Solar System Scope states that the maps are based on NASA elevation and imagery
data, with colors adjusted using spacecraft and Hubble observations. Some
unmapped planetary regions contain corresponding fictional terrain. JScene3D
redistributes the downloaded 2K files without pixel modifications.
